# Selected Works — портфолио дизайна

Главная страница объединяет два самостоятельных направления:

- Товарная инфографика Ренаты: EMBER, lume. и AURA. Три концепции по пять слайдов, галерея, фильтры и скачивание PNG или целой серии.
- Восемь интерактивных сайтов: MimiToys, MONOLIT, MOVE, Елена Соколова, Atelier Coffee, ATELIER HAIR, Тёплый Хлеб и WAYFARER.

Имя Ренаты и Telegram `@MusicalBlueLotus26` относятся к разделу товарной инфографики. Веб-проекты — отдельная коллекция.
Бренды и товары в новых сериях иллюстративны: это дизайн-концепции, не клиентские заказы.

Исходные изображения товаров и промпты описаны в `ASSET-BRIEFS.md`.
Серия AURA обновлена в контрастном стиле музыкальной афиши. Её макеты находятся в `tools/aura-v2.cjs`, текущие изображения — в `assets/marketplace/aura-v2/`. Прямая ссылка на серию сохраняется: `?project=aura#work`.
`tools/build-site.cjs` собирает главную страницу, `tools/build-marketplace.cjs` — 15 карточек 900 × 1200 px.
Стили новой главной находятся в `assets/premium.css`, галерея — в `assets/premium.js`.
Существующие страницы `projects/` и их общие стили и скрипты сохранены.

Перенесено с https://haevlob-design-collection.easy-mink-5389.chatgpt.site/.
Страницы, изображения, шрифты, стили и скрипты хранятся в этом репозитории.
Для работы сайта не нужны установка пакетов, сборка или сервер приложений.

## Публикация через GitHub Pages

1. Откройте https://github.com/haevlob/portfolio/settings/pages.
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. В **Branch** выберите **main**, папку **/ (root)** и нажмите **Save**.
4. Дождитесь завершения публикации в разделе **Actions**.

Адрес после включения GitHub Pages: https://haevlob.github.io/portfolio/.
После каждого обновления ветки `main` GitHub Pages публикует новую версию.

## Локальный просмотр

В каталоге репозитория выполните:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000/ в браузере.
Ссылки и ресурсы используют относительные пути, поэтому сайт работает
и в корне домена, и в подпапке `/portfolio/`.

## Содержимое

- `index.html` — главная страница коллекции.
- `projects/` — восемь отдельных сайтов.
- `assets/` — общие стили, скрипты, локальные шрифты и изображения.
- `.nojekyll` — публикация готовых файлов без обработки Jekyll.

Интерактивные формы, корзины и бронирования демонстрационные: реальные
заказы не создаются, данные форм не отправляются.
